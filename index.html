01 · COLLECTIONS
Arrays in C
An array stores a fixed number of values of the same type in consecutive memory locations.


1. Declaring, initializing, and indexing
Write the element type, array name, and number of elements in square brackets. C starts counting indexes at 0.
int scores[4] = {85, 92, 78, 90};
printf("%d\n", scores[0]); // 85
scores[1] = 95;             // update the second element
For scores[4], valid indexes are scores[0] through scores[3]. Accessing outside that range is undefined behavior; C does not check array boundaries automatically.


2. Traversing an array with a loop
A loop is the usual way to process every item. Start at zero and stop while the index is less than the element count.
int values[3] = {4, 8, 12};
int sum = 0;
for (int i = 0; i < 3; i++) {
    sum += values[i];
}
printf("sum = %d\n", sum);
The condition i < 3 visits indexes 0, 1, and 2. Using i <= 3 would try one extra element.


3. Finding the number of elements
When an array is declared in the same scope, sizeof can calculate its element count. This works while the expression still refers to the actual array.
#include <stddef.h>
int values[] = {4, 8, 12, 16};
size_t count = sizeof values / sizeof values[0];
When an array is passed to a function, it behaves like a pointer to its first element. Pass the count as a separate argument.


4. Two-dimensional arrays
A two-dimensional array can represent rows and columns. Every row has the same number of columns.
int grid[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
printf("%d\n", grid[1][2]); // 6
The first index chooses a row; the second chooses a column. Valid row indexes are 0–1 and column indexes are 0–2.


5. Arrays and C strings
A C string is a character array ending in the special null character '\0'. Leave space for it when declaring or copying a string.
char name[6] = "Mika"; // includes terminating '\0'
printf("%s\n", name);
An array that is not null-terminated cannot safely be used with string functions such as printf("%s", name).


Remember
Arrays have a fixed size once declared. Track the valid index range and pass the array length when a function needs it.


02 · ADDRESSES
Pointers in C
A pointer is a typed variable that stores the memory address of an object.


1. Declaring and initializing a pointer
The pointer type tells C what kind of object is at the stored address. Use & to get an existing variable’s address.
int count = 10;
int *ptr = &count; // ptr points to count
Read int *ptr as “ptr is a pointer to int.” In int *a, b;, only a is a pointer; b is an int.


2. Dereferencing: reading and changing a value
In an expression, unary * follows a pointer to access the object at that address. This is called dereferencing.
int count = 10;
int *ptr = &count;
printf("%d\n", *ptr); // reads 10
*ptr = 25;             // changes count
The * in a declaration means “pointer to”; the * in *ptr means “the value ptr points to.”


3. Null and uninitialized pointers
Never dereference an uninitialized pointer; it may hold an unpredictable address. A pointer that intentionally points nowhere can be initialized to NULL, but it must be checked before dereferencing.
int *ptr = NULL;
if (ptr != NULL) {
    printf("%d\n", *ptr);
}
Setting a pointer to NULL does not create an object; it makes the “points nowhere” state explicit.


4. Arrays and pointer arithmetic
In most expressions, an array name becomes a pointer to its first element. Adding one to an int * moves to the next int.
int nums[] = {4, 8, 12};
int *p = nums;
printf("%d\n", nums[1]);   // 8
printf("%d\n", *(p + 1)); // also 8
nums[i] is equivalent to *(nums + i). Stay within the array, and never dereference the one-past-the-end address.


5. Pointers as function parameters
C passes function arguments by value. Passing a pointer copies the address, letting a function access or update the original object.
void setToZero(int *value) {
    *value = 0;
}
int score = 90;
setToZero(&score); // score becomes 0
The caller passes an address with &score; inside the function, *value refers to the original score.


6. Dynamic memory: an introduction
malloc requests memory while the program runs. Check whether it returned NULL, use the memory, then release it with free.
#include <stdlib.h>
int *items = malloc(3 * sizeof *items);
if (items != NULL) {
    items[0] = 42;
    free(items);
}
After free(items), do not use the old address. Dynamic memory needs careful ownership and error handling.


Remember
A pointer is safe to dereference only when it points to a live object of the correct type.


03 · CUSTOM TYPES
Structures in C
A structure groups related fields under one type. The fields can have different C types.


1. Defining a structure and making a variable
Define the structure type first, then declare variables of that type. Each variable contains its own fields.
struct Student {
    int id;
    float gpa;
};
struct Student learner = {202501, 3.5f};
The semicolon after the closing brace is required. Initializer values follow the field declaration order.


2. Accessing and updating fields
Use the dot operator (.) when you have a structure variable.
printf("ID: %d\n", learner.id);
learner.gpa = 3.7f;
Use matching format specifiers: %d for int; %f for float in printf, because float arguments are promoted to double.


3. Pointers to structures and the arrow operator
If a pointer refers to a structure, use -> to access a field through it.
struct Student *ptr = &learner;
printf("%.1f\n", ptr->gpa);
ptr->gpa = 3.8f;
ptr->gpa is shorthand for (*ptr).gpa. Parentheses matter because the dot operator binds more tightly than unary *.


4. Arrays of structures
An array can hold several records of the same structure type. Combine an array index with the dot operator to access a field.
struct Student classList[2] = {
    {101, 3.2f},
    {102, 3.8f}
};
printf("%d\n", classList[1].id); // 102
A loop can process each record, just like any other array.


5. Passing structures to functions
Passing a structure directly copies its field values into the function parameter. Pass a pointer when the function should update the original or when copying a large structure is unnecessary.
void improve(struct Student *s) {
    s->gpa += 0.1f;
}
improve(&learner);
Use const struct Student * if a function needs to read a structure without changing it.


6. Nested structures and typedef
One structure can contain another. A typedef can provide a shorter alias for a structure type.
typedef struct {
    int month;
    int day;
} Date;
typedef struct {
    char name[30];
    Date birthday;
} Person;
Person p = {"Ari", {4, 12}};
printf("%d\n", p.birthday.month);
In standard C, typedef creates an alias; it does not create a different kind of object.


7. Copying structures and pointer fields
Structure assignment copies each field. If a field is a pointer, only the address is copied; the pointed-to data is not duplicated.
int number = 7;
struct Record { int *value; };
struct Record a = {&number};
struct Record b = a; // b.value points to the same int
printf("%d\\n", *b.value);
This is a shallow copy. Be careful when structures contain pointers, especially when allocating and freeing memory.


Remember
Use . for a structure variable and -> for a pointer to a structure. Structure assignment copies fields, including pointer addresses.
